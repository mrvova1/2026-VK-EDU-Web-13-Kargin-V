## Как запустить
1. Клонировать репозиторий.
2. Открыть \public\base.html в VSC
3. Запустить live сервер.
4. Открыть в браузере: `http://127.0.0.1`.
(Для выбора страницы снизу в части loadFragment заменить значение в ковычках на название нужной страницы)

## Роуты проекта
- `/base` — Главная страница (форма навигации)
- `/Question_page` — Страница вопроса
- `/Ask_Question_page` — Форма создания вопроса
- `/Questions_listing_page` — Форма просмотра вопросов
- `/Questions_listing_by_tag_page` — Форма просмотра вопросов по тегу
- `/Settings_page` — Форма настроек
